# Skill Name

## Purpose
One or two sentences: what this skill accomplishes and why.

## When To Use
The triggers/situations that should invoke this skill.

## Required Inputs
What the agent must have before starting (paths, contracts, decisions).

## Steps
Ordered, concrete steps. Reference real files and agents.

## Commands To Run
Real commands from `package.json` / the repo (e.g. `pnpm typecheck`,
`pnpm test`, `pnpm db:migrate`, `node scripts/update-wiki.mjs`).

## Files To Inspect
Real paths the skill reads or touches.

## Expected Output
What a successful run produces (a diff, a passing gate, an updated doc).

## Failure Signals
Symptoms that mean the skill is going wrong and should stop/escalate.

## Definition Of Done
The checklist that must be true to consider the skill complete.
